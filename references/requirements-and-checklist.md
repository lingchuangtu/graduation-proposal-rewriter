# 原始要求（权威来源，逐字保留）

> 以下内容来自用户提供的任务说明，是本 Skill 的验收依据。

毕业设计题目：【填写题目】

我会上传学校的开题报告Word模板（含范文）以及相关参考文献。

请根据我的毕业设计题目和参考文献，直接在上传的原始Word模板上进行改写，完成一份高质量的本科毕业设计开题报告。

具体要求：

1. 严格保留原模板格式：包括字体、字号、行距、缩进、页边距、表格、边框、页眉页脚、学校Logo、封面及整体排版等所有细节。必须在原Word文件基础上修改，不能重新创建文档。

2. 严格参考范文内容：保持原有章节结构、写作风格、段落层次和大致字数，结合新题目重新撰写，内容完整、专业、逻辑连贯，不能简单替换关键词。

3. 参考文献规范：充分结合我提供的文献撰写国内外研究现状，正确标注引用编号，不得编造文献或研究成果。

4. 图表处理：原有与新题目无关的图片和功能图统一替换为对应的文字占位符，保留原有位置和图题格式，无须绘制。

5. 排版质量：确保内容填入后无格式错乱、异常空白、表格变形等问题，整体篇幅尽量与范文接近。

6. 直接交付：无需反复询问，自动完成内容撰写、原模板修改及排版检查，最终提供可下载、可编辑的Word文件。

核心目标：争取10分钟内完成一份内容完整、格式与学校原模板高度一致、只需少量人工检查即可使用的开题报告。

# 逐项验收清单

交付前逐项核对；任一项未通过，回到对应步骤修正后再交付。

- [ ] **题目已填入**：封面及正文中的“毕业设计题目”均为用户给定的新题目，无残留“【填写题目】”或范文旧题目。（步骤 3）

- [ ] **原文件基础上修改**：交付件由原始模板复制而来并做定点修改；未新建空白文档重新排版，未更改样式定义与页面设置。（步骤 2、5）

- [ ] **格式全部保留**：字体、字号、行距、缩进、页边距、表格、边框、页眉页脚、学校 Logo、封面、整体排版与模板一致。（步骤 5）

- [ ] **结构贴近范文**：章节标题、顺序、层级、段落层次与范文一致，未自行增删主要章节。（步骤 3）

- [ ] **风格与篇幅接近**：写作风格延续范文，各章大致字数与范文接近，整体篇幅无明显膨胀或缩水。（步骤 3、5）

- [ ] **真正重撰而非替换**：围绕新题目重写论证，不存在仅把范文关键词或题目做字符串替换的痕迹；内容完整、专业、逻辑连贯。（步骤 3）

- [ ] **引用规范且真实**：国内外研究现状结合用户提供的文献撰写；正文引用编号与文末文献列表一一对应；无编造文献、数据或研究成果。（步骤 1、3）

- [ ] **图表已处理**：与新题目无关的图片和功能图已换成文字占位符，仍位于原位置，图题格式与编号保留，未重新绘制。（步骤 4）

- [ ] **排版无缺陷**：无格式错乱、异常空白、表格变形、孤行、跨页表格断裂等问题。（步骤 5、6）

- [ ] **直接交付**：最终提供可下载、可编辑的 Word 文件；过程中未反复询问；交付说明简短并标出少量待人工复核点。（步骤 7）
